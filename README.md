# OMP Usage

An Omarchy bar widget for Oh My Pi subscription usage.

It reads `omp usage --json` and shows every subscription authenticated in OMP, with provider icons, usage meters, reset times, and plan type. It supports Codex, Claude, and any future provider OMP reports.

Install by cloning the plugin into `~/.config/omarchy/plugins/` and add `omp.usage-monitor` to the bar layout.
